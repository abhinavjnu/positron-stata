# Explore data, results and graphs

- **Variables pane** — the variables in memory with types, formats and labels, plus the latest
  `e()` and `r()` results and your frames.
- **Data Explorer** — type `browse` (or click the dataset) for a spreadsheet view with sorting,
  filtering and column summaries. Value labels are shown instead of codes (setting
  `positron-stata.dataExplorer.showValueLabels`). Double-click a `.dta` file to view it without loading it.
- **Plots pane** — every graph (`scatter`, `twoway`, `histogram`, `marginsplot`, …) appears here, with history.
- **Help pane** — put the cursor on a command and press `F1`, or type `help regress` in the Console.
