# Run code

| Action | Linux / Windows | macOS |
|---|---|---|
| Run the statement under the cursor (or the selection) | `Ctrl+Enter` | `Cmd+Enter` |
| Run the whole do-file (`do`) | `Ctrl+Shift+D` | `Cmd+Shift+D` |
| Run the current cell | `Ctrl+Shift+Enter` | `Cmd+Shift+Enter` |
| Run the current section | `Ctrl+Alt+S` | `Ctrl+Alt+S` |

- Multi-line commands (`///` continuations, `{ … }` blocks, `#delimit ;`) run as one statement.
- **Run Cell** / **Run Section** links appear above `* %%` cells and `**#` sections.
- Type directly in the **Console** just like Stata's Command window.
- Press the Console's stop button to **Break** a long-running command.
