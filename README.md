# Stata Support for Positron IDE (`positron-stata`)

First-class Stata and OpenStata support for Positron IDE and VS Code with native **Variables Pane**, **Data Explorer**, **Plots Pane**, and standalone **`.dta` file inspection**.

---

## 🌟 Key Features

- **Dual-Engine Architecture**:
  - **StataNow 19.5 MP / SE (Official)**: Seamless in-process execution via PyStata and SFI using your licensed Stata installation.
  - **OpenStata (Rust Engine)**: Pure open-source, high-performance Stata replacement powered by Rust, Polars, and Arrow. **Zero Stata license required!**
- **Native Positron Variables Pane**:
  - Active datasets in memory appear as interactive tables with observation and variable counts.
  - Expand to view all variable names, storage types, formats, and variable labels.
- **Native Positron Data Explorer**:
  - View Stata datasets in Positron's spreadsheet viewer with column profiling histograms, summary statistics, search, sorting, and row filtering.
  - Opens automatically on `browse` or by clicking the spreadsheet icon in the Variables pane.
- **Vector Graphics & Plots Tab**:
  - Graphs generated by Stata commands (`scatter`, `twoway`, `histogram`, etc.) are captured as vector SVGs and rendered directly in Positron's **Plots** pane.
- **Standalone `.dta` Dataset Viewer**:
  - Double-click any `.dta` file in the file explorer to view it directly in Positron's Data Explorer (powered by DuckDB).
- **Stata Syntax Highlighting & Language Configuration**:
  - Comprehensive TextMate grammar for `.do`, `.ado`, `.mata`, and `.hlp` files.
- **Native Console Execution**:
  - Press `Ctrl+Enter` (`Cmd+Enter` on macOS) to execute selected code or the current line.
  - Press `Ctrl+Shift+D` (`Cmd+Shift+D` on macOS) to run the entire `.do` file.

## 📦 Installation

### Option 1: Install VSIX in Positron or VS Code
Download the latest `positron-stata-0.1.0.vsix` and run:

```bash
# In Positron
positron --install-extension positron-stata-0.1.0.vsix

# Or in VS Code
code --install-extension positron-stata-0.1.0.vsix
```

Alternatively, open Positron, press `Ctrl+Shift+P`, choose **Extensions: Install from VSIX...**, and select `positron-stata-0.1.0.vsix`.

### Option 2: Clone into Extensions Directory
```bash
git clone https://github.com/abhinavk/positron-stata.git ~/.positron/extensions/positron-stata
```

## ⚙️ Engine Configuration

You can select your preferred engine via the Command Palette:
1. Press `Ctrl+Shift+P` (or `Cmd+Shift+P`).
2. Run **`Stata: Select Stata Engine (Stata 19 MP / OpenStata)`**.
3. Choose either:
   - **StataNow 19.5 MP (Official)** (requires Stata license)
   - **OpenStata (Rust Engine)** (free, open source)

You can also set the default engine using environment variables:
```bash
# Use official Stata
export POSITRON_STATA_ENGINE=stata19
export STATA_HOME=/usr/local/stata19

# Or use OpenStata (Rust Engine)
export POSITRON_STATA_ENGINE=openstata
export OPENSTATA_BIN=/path/to/open-stata
```
